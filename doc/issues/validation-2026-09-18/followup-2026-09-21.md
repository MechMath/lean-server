# Validation follow-up — 2026-09-21

This report keeps the final results of the server fixes and historical replay.
Existing detailed evidence and replay scripts are indexed in the
[archive README](README.md); large per-record source and replay files are external.

## Implemented and tested

- Added strict proof verification and worker protocol v2. The current endpoint
  is `POST /verify_proof`; compile checks use `POST /check`. All worker messages
  now use v2; see the [current protocol](../../../protocol/README.md).
- Added declaration, fixed-definition, `sorry`, unsafe-dependency, and axiom
  policy checks.
- Raised the worker stdout limit to 8 MiB, bounded retained stderr to 64 KiB,
  and deduplicated exact repeated diagnostics.
- Applied one deadline across queueing and execution and hardened worker
  replacement and cancellation.
- Passed all 103 tests, including the real Lean worker and verifier.

All 566 included historical AXLE-pass disagreements now pass strict
verification. Two slow cases required a 600-second budget and completed in
approximately 419.4 and 596.5 seconds.

The compilation replay covered 2,951 historical infrastructure failures after
the same exclusions: 500 compiled, 2,450 returned normal compile rejection, and
one triggered the known `Nat.pow` panic. All 2,950 included historical NDJSON
failures therefore returned semantic results rather than transport errors.

## AXLE-failed / local-passed analysis

All 1,789 records were classified. The largest groups were 1,116 axiom-policy
rejections and 591 malformed formal statements. The strict verifier rejected
1,785 and accepted four: two historical AXLE timeouts and two documented API
compatibility differences involving definitional equality and placeholder
requirements.
